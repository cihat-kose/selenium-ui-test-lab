Task: Basic Calculator - Repeatable Operations with Assertions

1. Go to https://testsheepnz.github.io/BasicCalculator.html.
2. Enter each of these input pairs using the keyboard:
   - 27 and 4
   - 42 and 7
   - 85 and 9
   - 36 and 11
   - 91 and 13
3. For each pair, select every available calculator function:
   - Addition
   - Subtraction
   - Multiplication
   - Division (only integer division)
   - Concatenation
4. Compare the displayed answer with the expected result for that operation.
5. Clear the calculator after checking all five operations for a pair, then enter the next pair.

The fixed input pairs make failures reproducible: the same data produces the same expected answers on every run.
