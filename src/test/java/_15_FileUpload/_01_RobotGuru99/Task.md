# Task: Upload a File with Robot on Guru99

**Test class:** [FileUploadWithRobot.java](FileUploadWithRobot.java)

**Shared file:** `src/test/resources/upload-sample.txt`

Open the [Guru99 File Upload Demo](http://demo.guru99.com/test/upload/). Use Java Robot keyboard input to open the native file picker, paste the sample file path, accept the terms, submit the form, and check the upload confirmation.

This task requires a visible desktop session and depends on the native dialog's focus and tab order.
