Topic: CSS Selectors for Registration

This exercise uses CSS selectors for every field on the ParaBank public demo form. The test supplies fictional contact details and generates a fresh username for each registration attempt.

1. Go to https://parabank.parasoft.com/parabank/index.htm
2. Click the Register button.
3. Enter the fictional profile and contact values defined by the test into the corresponding fields.
4. Enter a unique username, a demo-only password, and the same password into the confirmation field.
5. Click the Register button.
6. Verify that the welcome message appears.
