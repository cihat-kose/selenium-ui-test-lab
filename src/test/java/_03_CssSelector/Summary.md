# CSS Selectors

CSS selectors describe elements by their HTML tags, attributes, classes, and IDs. For example, `input[name='email']` matches an input whose `name` is `email`, while `#submit` matches the element with ID `submit`.

[`RegistrationWithCssSelectorsTest`](RegistrationWithCssSelectorsTest.java) uses CSS selectors for every field in the Parabank registration form and checks the welcome message. Notice that periods in an ID such as `customer.lastName` must be escaped in a CSS ID selector.

The [practice folder](_01_Practice/Task.md) repeats common page interactions using CSS. It checks submitted form values, login text, search text, a calculator sum, and the closing of ordinary HTML dialogs. These are public demos and can change.

Compare these examples with the parallel [XPath chapter](../_04_XPath/Summary.md).
