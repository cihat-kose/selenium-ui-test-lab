# Selenium WebDriver Introduction

This first lesson shows a basic browser test from start to finish: open Chrome, navigate to a website, find controls, enter data, submit a form, and check the confirmation.

[`NinjaRegisterTest`](NinjaRegisterTest.java) completes a registration on the public Tutorialsninja demo. It creates a unique email address for each run and asserts that the account-created message appears.

The website is external, so the test needs internet access and can be affected by changes to the demo. Start with `Task.md` to see the steps before reading the test.
