# Combined exercises

Start these after learning individual Selenium interactions.

`BasicCalculatorTest` enters numbers with keyboard Actions, selects operations with `Select`, waits for the calculate button, and compares displayed answers with expected values. It repeats the calculation with randomly generated numbers.

This is a combined UI practice exercise. It is not a complete business workflow or an end-to-end final project. [Task instructions](_01_BasicCalculator/Task.md) list the operations to practice.
